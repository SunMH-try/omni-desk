# 如何把这套工具链接入新项目

这是一份“直接照做就行”的超短接入清单。

## 方式一：推荐做法

适合你已经拿到 `Git_Version_Toolkit` 文件夹或压缩包的情况。

### 第 1 步：准备目标项目

确保目标项目已经是一个 Git 仓库。

如果还不是：

```powershell
git init -b main
```

### 第 2 步：把工具链放进项目根目录

目标结构建议如下：

```text
your-project/
|- Git_Version_Toolkit/
|- src/
|- docs/
`- README.md
```

### 第 3 步：用安装脚本完成接入

在工具链所在目录执行：

```powershell
.\Git_Version_Toolkit\install.ps1 -TargetPath D:\你的项目目录
```

如果目标项目里已经有旧版本工具链：

```powershell
.\Git_Version_Toolkit\install.ps1 -TargetPath D:\你的项目目录 -Overwrite
```

### 第 4 步：开始日常使用

进入目标项目根目录后，最常用的是这两条：

```cmd
Git_Version_Toolkit\git-save.cmd "保存当前开发进度"
```

```powershell
.\Git_Version_Toolkit\scripts\git-tag-release.ps1 v0.1.0 "初始稳定版本"
```

---

## 方式二：直接复制

如果你不想跑安装脚本，也可以直接把整个 `Git_Version_Toolkit` 文件夹复制到新项目根目录。

复制完成后一样可以直接使用：

```cmd
Git_Version_Toolkit\git-save.cmd "保存当前开发进度"
```

---

## 接入后最少要记住的 4 件事

1. 新任务先开分支，不要长期直接改 `main`
2. 每 30 分钟到 1 小时至少保存一次
3. 每天下班前至少 push 一次
4. 每个稳定阶段打一个 tag

---

## 最常用命令

快速保存并推送：

```cmd
Git_Version_Toolkit\git-save.cmd "保存当前开发进度"
```

带时间戳保存：

```powershell
.\Git_Version_Toolkit\scripts\git-save.ps1 "保存当前开发进度" -Timestamp
```

只本地保存：

```powershell
.\Git_Version_Toolkit\scripts\git-save.ps1 "本地保存点" -SkipPush
```

打版本标签：

```powershell
.\Git_Version_Toolkit\scripts\git-tag-release.ps1 v0.1.0 "初始稳定版本"
```
